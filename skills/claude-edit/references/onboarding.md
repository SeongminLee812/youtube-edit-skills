# 첫 실행 — 채널 정보 읽기와 취향 질문

편집을 시작할 때 **작업 폴더 루트의 `profile.md`**를 먼저 본다. 없으면 이 문서대로 만든 뒤 원래 일을 이어 간다. 있으면 읽고, 이번 일에 필요한 칸만 비어 있을 때 그 칸만 묻는다. **다음 영상부터는 다시 묻지 않는다.**

## 원칙

- 한 번에 2~3개씩 묻는다. 질문은 모두 5개 안팎이다.
- 채널 링크·소개 문서로 알 수 있는 것은 묻지 않는다. 읽은 값은 "이렇게 읽었다"고 보여 주고 틀린 것만 고치게 한다.
- 편집에 필요한 것만 묻는다. 콘텐츠 기획·브랜드 전략은 묻지 않는다.
- 사용자가 "알아서"·"나중에"라고 하면 기본값(아래 표의 굵은 값)으로 진행하고 profile.md에 그렇게 적는다.

## 1. 입력 받기

> "편집할 영상 파일을 알려 주세요(원고가 있으면 함께). 그리고 채널 페이지 링크나 채널 소개 문서 중 하나를 주세요."

- 영상 파일(필수), 원고(선택), 채널 링크(`https://www.youtube.com/@핸들`) **또는** 채널 소개 문서(텍스트·PDF 등) 하나.
- 영상은 작업 폴더 안 `<영상 이름>/` 폴더에 두기를 권한다(없으면 만들어 옮기기 전에 묻는다).

## 2. 채널 정보 읽기

읽는 것: 채널 이름, 한 줄 소개, 최근 영상 10개 정도의 제목·길이, 업로드 주기, 말투(존댓말/반말), 썸네일에 자주 쓰는 색.

- **채널 링크면:**
  1. `yt-dlp --flat-playlist -J --playlist-end 10 --extractor-args "youtube:lang=ko" "<채널 URL>/videos"`로 채널 이름·소개·최근 영상 제목·길이를 읽는다. 제목이 다른 언어(자동 번역 제목)로 나오면 `lang`을 채널 언어로 바꾼다.
  2. 안 되면 채널 `/videos`·`/about` 페이지를 연다(브라우저·웹 읽기 도구).
  3. 그것도 안 되면 사용자에게 채널 이름과 말투만 묻는다.
  4. 썸네일 색: 최근 영상 몇 개의 작은 썸네일(`https://i.ytimg.com/vi/<영상 ID>/mqdefault.jpg`)을 임시 폴더에 받아 한 장으로 모아 보고, 글자·화살표·배경에 자주 쓰는 진한 색 2~3개를 고른다(평균색은 탁해지므로 눈으로 고른다). 쓴 뒤 임시 파일은 지운다.
- **소개 문서면:** 문서에서 채널 이름·소개·말투·브랜드 색을 찾는다. 없는 값은 비워 둔다.

읽은 결과를 5줄 안으로 보여 준다: 채널 이름 / 한 줄 소개 / 보통 길이·주기 / 말투 / 색 후보.

## 3. 취향 질문 (5개 안팎, 2~3개씩)

| # | 질문 | profile.md 키 | 고를 것(굵게 = 기본값) |
|---|---|---|---|
| 1 | 컷 템포를 어떻게 할까요? 이미 편집을 마친 영상이면 '컷 안 함'을 고르세요. | `cut_tempo` | 촘촘(말 사이 0.15초) / **보통**(0.25초 안팎) / 여유(0.4초) / 컷 안 함(자막·강조·모션만) |
| 2 | 자막 스타일은요? 지금 쓰는 CapCut 프로젝트 이름을 알려 주시면 그 자막 모양을 그대로 씁니다. | `capcut_template` · `subtitle_font` · `subtitle_color` · `subtitle_outline` | 템플릿 이름(권장) 또는 글꼴·색·외곽선 |
| 3 | 강조 자막(핵심 문장을 크게)을 넣을까요? | `emphasis` | 안 씀 / 적게(1분 1~2개) / **보통**(1분 2~4개) |
| 4 | 효과음과 배경음을 쓸까요? | `sfx` · `bgm` · `bgm_file` | 효과음 **씀**/안 씀, 배경음 씀/**안 씀**(쓰면 파일) |
| 5 | 모션 카드(숫자·단계·비교 같은 설명 카드)와 목차 전환(챕터가 바뀔 때 화면을 어둡게 덮고 번호·제목을 띄우는 3초 카드)을 쓸까요? 쓰면 목업을 보여 드릴 테니 고르세요. | `motion` · `chapter_transition` → (쓰면) 3-1 목업 → `motion_style` · `brand_color_1` · `brand_color_2` · `motion_font` | **씀**/안 씀. 쓰면 목업에서 조합 번호 하나 |

- 1·2를 먼저, 3·4·5를 다음에 묻는다. 5번에 '씀'이면 바로 3-1 목업으로 간다. '안 씀'이면 3-1을 건너뛴다.
- 그 밖에 필요할 때만 묻는 것: 채널 범퍼 파일(`bumper`, 도입부 뒤에 넣는 짧은 로고 영상), 받아쓰기가 자주 틀리는 고유명사(`asr_prompt` — 최근 제목에서 뽑은 후보를 보여 준다), 챕터 표기 스타일(`chapter_style` — youtube-chapter-timestamps를 쓸 때, 최근 설명란에 챕터가 있으면 그 형식을 보여 준다).

## 3-1. 모션 카드 목업 컨펌 (모션·목차 전환을 쓸 때만)

1. **키 컬러 후보 2~3개**: 채널 링크가 있으면 최근 썸네일에서 자주 쓰는 진한 색을 뽑는다. 소개 문서만 있으면 사용자에게 브랜드 색을 묻는다(모르면 중립 후보 `#E8590C`·`#1C7ED6`·`#2F9E44`를 제안).
2. **목업 만들기**: 색 후보 × 스타일 2개(어두운 유리 / 밝은) 중 대표 조합 3~4개, 조합마다 카드 4장(챕터 제목·숫자·단계·목차 전환). 카드 글자는 채널·영상의 실제 주제로 채운다.
   ```
   python <스킬 폴더>/claude-edit/scripts/mockups.py --colors "#색1,#색2" --styles dark,light --topic "<주제>" --channel "<채널 이름>" \
       [--title "<챕터 제목>"] [--number "<제목>,<처음>,<지금>,<단위>"] [--steps "가|나|다"] [--chapter "1|<부제>|<제목>"] \
       --out <영상 폴더>/편집/목업/
   ```
3. **고르게 하기**: `<영상 폴더>/편집/목업/mockups.html`(한 화면 비교, 조합별 한 줄에 카드 4장)을 열어 보여 주고 조합 번호를 받는다. PNG는 에이전트가 먼저 직접 열어 글자 넘침·한글 깨짐·색을 확인한다.
- 밝은 노랑처럼 옅은 키 컬러는 밝은 스타일에서 흰 글자 대비가 약하다(목업에서 확인). 그런 색은 어두운 유리 스타일을 권한다.
4. **저장**: 고른 조합을 profile.md에 쓴다 — `motion_style: dark|light`, `brand_color_1: <키 컬러>`(목차 전환도 이 색), 보조색을 정했으면 `brand_color_2`, 글꼴을 정했으면 `motion_font`. 이후 영상은 다시 묻지 않고 이 스타일로 렌더한다.

## 4. profile.md 저장

[profile.template.md](profile.template.md)를 작업 폴더 루트에 `profile.md`로 복사해 채운다. 저장한 값을 사용자에게 한 번 보여 준다. 스크립트가 읽는 것은 `키: 값` 줄뿐이다(색은 `#RRGGBB`).

## 5. 이후

- 취향 값이 바뀌면 `profile.md`를 고친다.
- 편집하며 받은 그 밖의 선호는 claude-edit [preferences.md](preferences.md), 컷·자막 엔진 수치는 smartdaddy-video-edit `references/rules.md`의 '내 규칙', 시행착오는 [lessons.md](lessons.md)에 쌓는다.
