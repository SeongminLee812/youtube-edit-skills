# 사용자 선호 (기본값)

편집을 시작할 때마다 읽는다. 사용자의 최신 말이 이 문서와 다르면 최신 말을 따르고, 여기에 고쳐 적는다. 채널 정보(이름·색·범퍼 등)는 작업 폴더 루트의 `profile.md`가 기준이다([onboarding.md](onboarding.md)).

새 규칙은 아래 형식으로 해당 절 맨 아래에 더한다(숫자로 쓴다). 이유는 사용자 말을 그대로 옮기지 말고 한 줄 평서문으로 요약한다.
```
- [YYYY-MM-DD] 규칙 한 줄
  왜: <이유 한 줄> (영상 · 위치)
```

비어 있는 절은 아직 정한 것이 없다는 뜻이다. 그때는 스킬 본문과 smartdaddy-video-edit `references/rules.md`의 기본값을 쓰고, 사람이 정해야 할 것(내용 컷·크레딧·결제·신뢰도 낮은 컷)만 묻는다.
