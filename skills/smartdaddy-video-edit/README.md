# 스마트대디 영상 편집 스킬 (v2 · 2026-10-21)

클로드에게 영상 편집을 맡길 때 쓰는 스킬입니다. 유튜버 스마트대디가 석 달 동안 클로드와 영상을 만들며 받은 피드백과, 실제로 쓰던 도구를 묶었습니다.

녹화본을 주면 클로드가 다시 말한 곳과 긴 쉼을 자르고, 의미 단위 자막을 달고, 효과음·줌·모션 카드·강조 글자까지 얹어서 **CapCut 프로젝트**로 만들어 줍니다. 전부 따로따로 된 클립이라, CapCut에서 클립 끝을 잡아 늘리고 줄이며 마지막 손질을 하면 됩니다. 그리고 여러분이 준 피드백을 이 스킬의 규칙으로 저장해, 다음 영상에서 같은 말을 두 번 하지 않게 합니다.

> 딸깍 한 번에 완성본이 나오지는 않습니다. 받아쓰기, 초벌 조립, 자막, 모션 카드는 클로드가 잘합니다. 컷 디테일, 구성, 재미, 어디를 버릴지는 아직 사람 몫입니다.

## 설치

1. **클로드 데스크톱 앱**을 열고 위쪽에서 채팅 말고 **Code**를 누릅니다. 영상 파일을 넣어 둘 작업 폴더를 하나 만들어 열어 줍니다(처음엔 폴더 접근 허용 창이 뜹니다).
2. 받은 `smartdaddy-video-edit.zip`을 대화창에 끌어다 놓고 **"이 스킬 설치해 줘"**라고 말합니다.
3. 이어서 **"편집 스킬 점검해 줘"**라고 말합니다. 빠진 프로그램이 있으면 알려 주고, "알아서 설치해 줘"라고 하면 설치까지 합니다.

직접 넣고 싶으면 zip을 풀어 `smartdaddy-video-edit` 폴더를 통째로 스킬 폴더에 넣으면 됩니다.
- Windows: `C:\Users\<사용자 이름>\.claude\skills\`
- Mac: `~/.claude/skills/`

> **클로드에게(설치를 맡았을 때):** zip 안의 `smartdaddy-video-edit/` 폴더를 사용자 스킬 폴더(`~/.claude/skills/`)에 넣는다. 같은 이름의 폴더가 이미 있으면 덮어쓰기 전에 기존 `references/rules.md`의 `## 내 규칙` 아래 내용을 새 `rules.md`의 같은 자리로 옮기고, 기존 폴더는 `smartdaddy-video-edit_backup_<날짜>`로 남긴다. 끝나면 설치한 경로를 알려 주고, 스킬이 바로 안 잡히면 새 대화를 열어 달라고 안내한다.

## 이렇게 말해 보세요

**전체 초안 (12분 영상 기준 1~2시간)**
```
녹화본 폴더에 있는 원본으로 15분 내외 영상 초안 만들어 줘. 컷 편집, 효과음, 모션그래픽, 줌인 줌아웃까지. 끝나면 캡컷 프로젝트로 만들어서 내가 이어서 편집할 수 있게 해 주고, 위스퍼 같은 필요한 도구는 알아서 설치해 줘.
```

**짧은 연습 (처음엔 이걸로)**
```
중간중간 버벅이는 부분 자르고, 자막 달아서, 캡컷 프로젝트로 만들어 줘.
```

**피드백 → 규칙 저장 (제일 중요)**
```
37초에 "여러, 여러" 같은 말 두 번 했잖아. 이렇게 반복한 말은 항상 앞에 걸 자르고, 마지막 것만 남겨 줘.
오늘 고친 거 스킬에 저장해 줘.
```

**그 밖에**
- `대본은 이 파일이야. 자막은 대본 표기대로 맞춰 줘.`
- `1:24랑 3:05, 자막이 너무 빨리 사라져. 0.2초씩 늦게 빼 줘.`
- `편집 시간이 30시간에서 8시간으로 줄었다는 숫자 카드 4초짜리 만들어 줘.`
- `내보낸 최종본 점검해 줘.`

## 처음엔 이렇게

- 예전에 찍어 둔 아무 원본이나, 1분짜리 짧은 영상부터 맡겨 보세요.
- 피드백은 "몇 초에 뭐가 어떻다"로 구체적으로.
- 고친 건 꼭 "스킬에 저장해 줘"라고 시키세요. 그래야 다음 영상에서 같은 실수를 안 합니다. 여러분 규칙은 `references/rules.md` 맨 아래 `내 규칙`에 쌓입니다.

## 필요한 것

- 클로드 데스크톱 앱과 Claude Code를 쓸 수 있는 유료 요금제(월 20달러 이상 권장)
- CapCut 데스크톱 앱 (Windows 또는 Mac). 평소 자막 스타일이 들어 있는 프로젝트가 하나 있으면 그 스타일을 그대로 씁니다.
- Python 3.10 이상, ffmpeg — 없으면 클로드가 설치를 도와줍니다.
- 있으면 좋은 것: NVIDIA 그래픽카드(받아쓰기가 빨라집니다), 무료 글꼴 Pretendard(모션 카드용)

## v2에서 달라진 것 (2026-10-21)

- 효과음·줌·모션 카드·강조 글자·배경음을 CapCut 프로젝트에 각각 따로 얹습니다. 박자는 실제로 말한 낱말에 맞춥니다.
- 대본을 주면 자막이 대본 표기로 나옵니다("채찌피티" → "챗GPT", "삼십 시간" → "30시간").
- "알아서 설치해 줘"라고 하면 필요한 프로그램(Python 패키지, ffmpeg 등)을 설치합니다.
- 저작권 걱정 없는 기본 효과음 7개를 만들어 씁니다.
- 남긴 문장 클립을 하나씩 다시 받아써서 놓친 반복·"다시"·끝 잘림을 찾아 줍니다.
- 모션 카드를 어두운 유리 카드 스타일로 바꾸고 종류를 늘렸습니다.
- 최근 영상 피드백(모션 반복 금지, 실제 화면 섞기, 말 끝 잘림 방지, 내레이션 속도 등)을 규칙에 더했습니다.

## 주의

- 클로드가 CapCut 프로젝트를 설치할 때는 CapCut을 꺼 주세요. 켜져 있으면 설치하지 않습니다.
- 원본 파일과 기존 CapCut 프로젝트는 고치지 않고, 항상 새 이름으로 만듭니다.
- CapCut 업데이트로 프로젝트 파일 형식이 바뀌면 조립 기능이 안 될 수 있습니다. 이때도 받아쓰기, 컷 목록, 자막(SRT), 모션 카드는 쓸 수 있습니다.
- 글꼴·음악 파일은 들어 있지 않습니다. 배경음은 여러분이 고른 곡을 씁니다.

자유롭게 쓰고 고쳐서 쓰셔도 됩니다. 여러분 취향의 규칙이 쌓일수록 여러분만의 편집자가 됩니다.
