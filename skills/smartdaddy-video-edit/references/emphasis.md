# 강조 포인트 — 어떤 말을, 어떻게 강조하나

롱폼에서 강조 자막·확대·효과음·옆 스티커·목차 이름표를 넣을 때 보는 기준이다. 아래 값은 시작용 기본값이다. 사용자가 새 피드백을 주면 이 문서의 표를 고친다. 쓸지 말지와 정도는 `profile.md`의 `emphasis`(안 씀·적게·보통)·`sfx`·`bgm`을, 목차 이름표 번호 색은 `chapter_color`를 따른다.

## 1. 강조 포인트 6유형

한 문장은 한 유형이다. 아래 여섯에 들지 않으면 강조하지 않는다.

| 유형 | 뜻 | 예 | 글에서 보이는 표지 | 색 낱말 | 효과음 |
|---|---|---|---|---|---|
| 훅 | 대상을 지목하고 볼 이유를 약속 | "처음 시작하는 분들은 이것만 보세요!" | ~분들·여러분·~라면 + 이것만·보세요 | 노랑 | 차임 `ding` |
| 원인지목 | 원인·정답을 가리키며 궁금하게 함 | "제가 실패했던 이유가 딱 이거였어요" | 이유·원인 + 딱·이거·바로 이 | 노랑 | 차임 `ding` (가까우면 `pop`) |
| 공감 | 시청자 고민, 진행자의 실패·고생 고백 | "그때는 정말 아무것도 손에 안 잡혔어요" | 제가·저는 + 과거형, 아예·도저히·진짜, 힘든·사라졌·실패 | 없음 | 짧은 뾱 `pop` 또는 없음 |
| 정정 | 흔한 생각을 바로잡음 | "그런데 그건 여러분 탓이 아니에요" | 아니에요·필요 없·안 맞·하지 마 | 보조색 | **없음** |
| 결과 | 수치·변화로 기대감을 줌 | "한 달 만에 시간이 절반으로 줄었습니다" | 숫자+단위 + 늘었·줄었·빠졌 | 노랑 | 상승 `rise` |
| 핵심 | 주장·행동 지시 | "하루 10분만 따로 떼어 두세요" | 숫자+단위, 하세요·드세요 | 노랑 | 차임 `ding` |

- 정보를 정리하는 말보다 **시청자를 붙잡는 말과 진행자의 솔직한 경험**을 먼저 본다.
- 같은 시간 카드·사진이 같은 말을 이미 보여 주면 강조하지 않는다.

## 2. 후보 뽑기 — 특징 점수

`scripts/emphasis_candidates.py`가 자막 문장마다 글 특징과 소리 특징을 뽑아 점수순 CSV를 낸다. 도구는 후보만 내고, 최종 선택은 사람이 한다.

```bash
python <스킬 폴더>/smartdaddy-video-edit/scripts/emphasis_candidates.py <프로젝트> --out 후보.csv [--start 0 --end 92] [--truth "문구|문구"]
```

| 글 특징 | 점수 | 소리 특징 (웨이브폼) | 점수 |
|---|---|---|---|
| 지시·예고(이거·이것만·딱·바로 이) | +2 | 평균 음량 z값 | ×0.4 |
| 부정 단언 | +2 | 앞 쉼 0.25초 이상 | +0.3 |
| 대상 지목 | +1.5 | 뒤 쉼 0.25초 이상 | +0.3 |
| 극단 부사(아예·절대·진짜·무조건·도저히·그냥) | +1.5 | 말이 느려짐 | +0.3 |
| 숫자+단위 | +1.5 | 음높이 폭이 큼 | +0.3 |
| 1인칭 고백 · 수치 변화 · 고통·상실 · 명령 어미 | 각 +1 | | |
| 질문형 · 13자 이하 | 각 +0.5 | | |
| 챕터 제목("첫 번째…") | −3 | | |

- 25자를 넘는 문장은 쉼표·연결어미로 나눈 구절 가운데 점수가 가장 높은 구절만 강조한다.
- 글 점수가 1 미만이면 소리만으로는 후보가 되지 않는다.
- 결과 유형은 점수가 낮게 나오기 쉬우니 숫자+변화 문장은 따로 훑는다.
- 편집본은 쉼을 줄여 놓아 쉼 특징이 약하다. 쉼을 보려면 컷 전 원본 소리를 `--audio`로 준다.
- 사용자가 새로 고르거나 뺀 문장이 생기면 `--truth`로 순위를 다시 보고 가중치를 고친다. 한 문장에만 맞는 규칙은 넣지 않는다.

## 3. 화면에 넣는 것

| 요소 | 값 |
|---|---|
| 강조 자막 | 항상 한 줄, 그 문장 전체, 기본의 2.4배(폭 80% 안으로 줄임 — 13자 이하만 2.4배 그대로, 17~22자는 1.5~2배), 흰 글자 + 검은 외곽선, 색 낱말 한 구절 |
| 확대 | 강조 문장이 뜨는 프레임에 1.2배로 바로 커지고, 문장이 끝나는 프레임에 바로 돌아온다. 머리 위가 잘리지 않게 위쪽 기준. 전체 화면 사진·카드가 덮은 구간에는 넣지 않는다 |
| 효과음(`sfx: 씀`) | 1절 표. −20dB, 1분에 3개까지, 같은 소리는 20초 안에 다시 쓰지 않는다, 연달아 강조의 두 번째에는 넣지 않는다. 사람 목소리가 든 효과음은 쓰지 않는다 |
| 옆 스티커 | 말하는 사물·개념이 분명한 곳에 오른쪽 위(중심 x 1655·y 320, 460×500). 본인 사진(흰 테두리·둥근 모서리·−3° 기울임)이나 이모지 + 라벨. 3프레임에 튀어나와 4~6초 머문다. 얼굴(x 520–1400)·자막·기존 카드와 겹치지 않게 |
| 목차 이름표(선택) | 왼쪽 위(상자 왼쪽 64px, 중심 y 101px)에 지금 챕터 이름. 흰 상자 + 진한 글자, 번호만 키 컬러(`profile.md` `chapter_color`). 도입부(첫 챕터 전)에는 띄우지 않는다. 범퍼·전체 화면 자료·챕터 전환 막 위에서는 숨긴다 |
| 빈도 | `emphasis: 보통`이면 1분에 2~4개, `적게`면 1~2개. 시작 사이 4초 이상, 연달아 두 문장까지 |

## 4. 넣는 도구

```bash
python <스킬 폴더>/smartdaddy-video-edit/scripts/emphasis.py --project <프로젝트 이름|폴더> --spec <json> --out <새 스테이징 폴더> --audio-template <템플릿 프로젝트> [--dry-run] [--install --name <새 이름>]
```

- spec: `{"style": {덮어쓸 값}, "items": [{"id", "match", "at", "kind": "훅|원인지목|공감|정정|결과|핵심", "color_word", "sfx": true|false|"pop", "zoom": false, "phrase", "split_at"}], "toc": {"items": [{"at", "text", "num"}]}, "stickers": [{"id", "at", "dur", "emoji"|"image", "label", "pos": "right_top"|"left_mid"}]}`
- 배경음악(`profile.md` `bgm: 씀`일 때): spec 최상위 `"bgm": {"file", "start", "end", "db", "fade_in", "fade_out", "loop": true, "skip": "bumper", "gaps": [[a, b]]}`. 범퍼처럼 자체 소리가 있는 클립은 비우고, 곡이 짧으면 반복한다(이음매 0.15초 페이드). 실행할 때 목소리 음량을 재서 "목소리보다 15dB 아래"가 되는 클립 볼륨을 출력하고, 지정값이 ±4dB를 벗어나면 `[규칙 점검]`이 나온다.
- 배경음악 시작: 도입부 처음은 음악 없이 두고 분위기가 바뀌는 첫 문장에서 0.3초 페이드로 들어오는 것을 시작값으로 제안한다. 말할 때 따로 줄이지 않는다(낮은 고정 크기).
- 효과음·배경음 클립에는 템플릿의 음량 정규화 재료를 붙이지 않는다.
- 원본 프로젝트는 읽기만 하고 새 스테이징에 쓴다. 트랙 순서: 메인 → 강조 확대 → 기존 사진·모션 → 강조 스티커 → 자막 → 목차 이름표 → 강조 효과음. 지우면 원래 화면이 나온다.
- 출력의 `[규칙 점검]`·`[겹침 확인]`·`[못 넣음]`을 보고 고친다.
- `preview.py`는 낱말 색·그림자·글자 크기를 제대로 그리지 못하므로 스테이징 값을 읽어 따로 그려 확인한다(글자 크기 1 = 1080p에서 11.72px).
- 배속 판(선택)은 강조·배경음을 넣은 뒤 `claude-edit` `scripts/speed_version.py`로 만든다. 배경음은 배속하지 않고 새 시각표 위에 원래 빠르기로 다시 깐다.

## 5. 아직 확인하지 못한 것

- CapCut에서 열었을 때 강조 글꼴·외곽선·그림자, 목차 상자 크기, 확대 클립 위치, 스티커 알파가 미리보기와 같은지.
- 이모지 스티커는 작은 그림을 키운 것이라 조금 흐리다. 계속 쓰려면 큰 그림으로 바꾼다.
