# 처음 쓰는 분을 위한 안내

클로드가 이 문서를 읽고 사용자를 단계별로 안내한다. 사용자가 할 일과 클로드가 할 일을 구분해서 말한다.

## 준비물

1. **클로드 데스크톱 앱**과 유료 요금제(Claude Code를 쓸 수 있는 요금제). 앱 위쪽에서 채팅 말고 **Code**를 쓴다.
2. **작업 폴더 하나.** 편집할 영상 파일을 넣어 둔다.
3. **CapCut 데스크톱 앱.** 클로드가 만든 프로젝트를 여기서 연다. 평소 자막 스타일이 들어간 프로젝트가 하나 있으면 그걸 템플릿으로 쓴다(없으면 CapCut에서 영상 하나·음성 파일 하나·자막 한 줄을 넣은 프로젝트를 만들어 저장해 달라고 한다).
4. 컴퓨터에 **Python 3.10 이상**과 **ffmpeg**. 없으면 클로드가 설치한다(사용자가 맡겼을 때).
5. 있으면 좋은 것: NVIDIA 그래픽카드(받아쓰기가 빨라진다). 없어도 CPU로 된다(느리다).

## 설치 순서

1. 스킬 zip을 클로드 대화창에 끌어다 놓고 "이 스킬 설치해 줘" → 클로드가 `~/.claude/skills/smartdaddy-video-edit/`에 넣는다. 이미 있던 버전이 있으면 `내 규칙`을 새 버전으로 옮긴다(README의 '클로드에게' 참고).
2. 클로드 데스크톱 앱에서 작업 폴더를 연결한다. 처음 한 번은 폴더 접근을 허락하라는 창이 뜬다. 허용을 누른다.
3. 사용자: **"편집 스킬 점검해 줘"** → 클로드가 `python scripts/doctor.py`를 돌려 빠진 것을 알려 준다.
4. 사용자가 "알아서 설치해 줘"라고 하면 `python scripts/doctor.py --fix`. Python 패키지(`scripts/requirements.txt`), 모션 카드용 크로미움, 없으면 ffmpeg(Windows는 winget, Mac은 brew)를 설치하고 다시 확인한다.
5. 받아쓰기 모델은 처음 받아쓰기 때 한 번 내려받는다(large-v3 약 3GB, 몇 분).

## 첫 1분 영상

1. 예전에 찍어 둔 영상이나 폰으로 찍은 1분짜리 말하는 영상을 작업 폴더에 넣는다. 일부러 한두 번 버벅여도 된다.
2. 클로드에게 한 문장만 보낸다:
   > 중간중간 버벅이는 부분 자르고, 자막 달아서, 캡컷 프로젝트로 만들어 줘.
3. 클로드가 컷 목록(무엇을 잘랐는지)을 보여 준다. 확인하고 CapCut을 끈 뒤 "설치해"라고 한다.
4. CapCut을 열면 프로젝트 목록 맨 위에 새 프로젝트가 있다.
5. 마음에 안 드는 걸 하나만 말한다. 예: "37초에 같은 말 두 번 했잖아. 반복한 말은 항상 앞에 걸 자르고 마지막 것만 남겨 줘."
6. 끝나면: **"오늘 고친 거 스킬에 저장해 줘."**

익숙해지면 전체 초안을 맡긴다:
> 녹화본 폴더에 있는 원본으로 15분 내외 영상 초안 만들어 줘. 컷 편집, 효과음, 모션그래픽, 줌인 줌아웃까지. 끝나면 캡컷 프로젝트로 만들어서 내가 이어서 편집할 수 있게 해 줘.

## 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| CapCut 목록에 안 보임 | CapCut을 완전히 껐다가 다시 열기. 설치할 때 CapCut이 켜져 있었는지 |
| 효과음이 다른 소리로 나옴 | 효과음을 CapCut 라이브러리에서 복제했는지(`references/capcut.md` 함정 1) |
| 줌이 처음부터 확대돼 있음 | 키프레임 시각 기준(`references/capcut.md` 함정 2) |
| 재생이 끊김 | 원본 해상도·키프레임 간격(`references/capcut.md` 함정 3) |
| 받아쓰기가 너무 느림 | 그래픽카드가 없으면 `--model medium`으로 |
| 말 중간이 잘림 | `cuts.md`에서 그 자리를 찾아 "여기 자르지 마"라고 말하고, 규칙으로 저장 |
| 효과음·줌이 엉뚱한 데 들어감 | 조립 출력의 `[못 넣음]`과 `_timeline.json`의 덧입히기 목록을 보고 `overlays.json`의 낱말을 고친다 |
| ffmpeg를 설치했는데 못 찾음 | 스크립트가 winget·brew 설치 위치를 스스로 찾는다. 그래도 안 되면 클로드 앱을 다시 연다 |

## 기대치

이 스킬은 **딸깍 한 번에 완성본을 주지 않는다.** 받아쓰기, 초벌 조립, 자막 초안, 모션 카드는 잘한다. 컷 디테일과 효과음 양은 사람이 한 번 봐 줘야 한다. 재미 판단, 구성, 어디를 버릴지는 아직 사람 몫이다. 대신 사람이 하는 일이 "자르고 붙이기"에서 "보고 말하기"로 바뀐다.
