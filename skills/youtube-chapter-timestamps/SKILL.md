# 완성 영상 유튜브 챕터 제작

> **0단계 — 채널 프로필:** 작업 폴더 루트에 `profile.md`가 있는지 먼저 본다. 없으면 [온보딩](../claude-edit/references/onboarding.md)대로 채널 링크나 소개 문서를 받아 만든 뒤 시작한다(한 번에 2~3개씩, 링크로 알 수 있는 것은 묻지 않음). 이 스킬에서 더 확인할 것: 챕터 표기 스타일(`chapter_style`).

사용자가 지정한 최종 편집본(예: `업로드본.mov`, `final`, `crop` 등)의 실제 오디오를 기반으로 챕터를 만든다. 촬영 원고의 예상 시간만으로 타임스탬프를 추정하거나 전체 길이에 비례 배분하지 않는다.

## 작업 순서

1. **원본 미디어 확인:** 사용자가 지정한 정확한 영상/오디오 파일을 확인한다(`업로드본.mov`, `crop`, `final`, `short` 등). 원본 미디어 파일은 절대 수정하지 않는다.
2. **인근 원고·기획안 확인:** 해당 영상 폴더에 원고·기획안이 있으면 읽는다(없으면 건너뛴다).
3. **실행 환경 확인:** `ffmpeg`, `ffprobe`, `whisper-cli`, 다국어 GGML Whisper 모델을 확인한다. 현재 호스트에서는 `~/.codex/models/whisper/ggml-small.bin`(또는 `WHISPER_MODEL` 환경변수)을 우선 사용한다. 도구·모델이 없으면 임의로 설치하거나 외부 클라우드 전사 서비스를 쓰지 말고 사용자에게 먼저 확인한다.
4. **음성 전사 실행:** [scripts/transcribe_video.py](scripts/transcribe_video.py)를 실행한다. 인근 원고에서 확인한 제품명·인명·전문 용어를 `--prompt`에 짧게 넣어 인식률을 높인다. 한국어 영상은 기본 `--language ko`와 `small` 이상 다국어 모델을 사용한다.
5. **실제 발화 시작점 판정:** 생성된 SRT 또는 JSON 전사 결과를 확인한다. 오인식된 단어는 원고의 정확한 표기로 교정하되 시간은 반드시 실제 오디오 발화에 고정한다. 각 새 주제를 여는 첫 문장의 시작 시각을 사용하며, 첫 음절이 잘리지 않도록 **해당 초 단위로 내림(floor)**한다.
6. **의미 단위 묶기:** 문장마다 쪼개지 말고 시청자의 한 질문에 답하는 도입·근거·설명을 하나의 의미 있는 챕터로 묶는다. 챕터는 적게 둔다. 8분 안팎 영상은 5개 정도로, 도입과 큰 구간 시작만 남긴다.
   - **이름은 주제 키워드로 짓는다.** 타임스탬프는 설명란의 일부이고, 설명란은 검색 노출에 영향을 준다. 영상의 `10_검증/` 조사와 업로드 체크리스트의 키워드 표에서 검색어를 가져와 `검색 키워드: 구체적인 답` 형식으로 쓴다. 자세한 기준은 `.skill-build/claude-edit/references/upload_pack.md` 0·2절이다.
7. **결과 파일 저장:** 업로드 폴더(`업로드/`)에 바로 붙여넣기용 텍스트 파일(`업로드_타임스탬프.txt` 또는 `유튜브_타임스탬프.txt`)을 저장하고, 필요하면 원본 파일명·전체 길이·각 경계의 실제 발화 문구를 기록한 Markdown 노트를 함께 남긴다.
8. **규칙 검증:** 납품 전 [scripts/validate_chapters.py](scripts/validate_chapters.py)에 챕터 파일과 `ffprobe`로 확인한 영상 길이를 넣어 검증한다. 오류가 있으면 수정 후 다시 검증한다.

## 유튜브 챕터 규칙

- 첫 챕터는 반드시 `00:00`에 시작한다.
- 최소 3개 이상의 타임스탬프를 포함한다.
- 타임스탬프는 엄격한 오름차순이어야 한다.
- 마지막 챕터를 포함해 모든 챕터의 길이는 최소 **10초 이상**이어야 한다.
- 제목은 대사 문장 전체를 붙여넣지 말고, 앞에 사람들이 검색할 키워드를 두고 뒤에 해당 구간에서 얻을 답을 짧고 구체적으로 적는다. 예: `아침 루틴: 알람 한 번에 일어나는 3단계`. 채널 표기 방식은 `profile.md`의 `chapter_style`을 따른다.
- 그 구간에서 실제로 다루는 말만 쓴다. 영상이 다루지 않는 인기 키워드를 넣지 않는다. 번호만 있는 제목(`①`, `첫 번째`)은 쓰지 않는다.
- 영상 길이가 1시간 미만이면 `MM:SS`, 1시간 이상이면 `H:MM:SS` 형식을 사용한다.
- 영상 끝까지 10초 미만만 남았다면 별도의 마무리/CTA 챕터를 분리하지 않는다.

## 실행 명령

전사 실행:

```bash
python3 scripts/transcribe_video.py \
  "/absolute/path/to/video.mov" \
  --output-dir "/absolute/path/to/transcript-output" \
  --language ko \
  --prompt "<채널 이름>, <고유명사>, <전문 용어>"
```

챕터 텍스트 파일 검증:

```bash
python3 scripts/validate_chapters.py \
  "/absolute/path/to/업로드_타임스탬프.txt" \
  --duration 490.0
```

## 납품 기준

답변 맨 앞에 유튜브 설명란에 바로 복사·붙여넣기 할 수 있는 코드 블록을 제시한다. 사용한 정확한 미디어 파일명과 전체 길이를 함께 보고하고, 저장한 챕터 파일·전사 산출물 링크를 연결한다. 발화 겹침·소음 등으로 경계가 불확실한 구간이 있으면 해당 타임스탬프와 사유를 명시한다. 프로젝트에 새 Markdown 문서를 추가한 경우 `INDEX.md`, `tools/wiki_catalog.json` 갱신 및 `python3 tools/build_docs_wiki.py`, `python3 tools/check_docs.py` 검사를 수행한다.
